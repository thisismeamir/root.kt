# ROOT.kt

ROOT.kt is a kotlin package to read and write `.root` files (which are the standard file extension in high energy physics) directly in Kotlin; without the use of binded C++/C code or other tricks.

The main reason of development is to be able to have an easier development experience in high-energy physics using [partikle]("https://github.com/thisismeamir/partikle").
